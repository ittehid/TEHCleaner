# Security Policy

TEHCleaner удаляет только явно перечисленные категории временных данных. Новые cleaners должны использовать минимально необходимую область удаления и не должны следовать reparse points / junctions за пределы целевого каталога.

Не добавляйте эвристическое удаление ключей реестра, драйверов, служб, WinSxS или системных компонентов без документированной модели безопасности и восстановления. Разрешённая очистка MRU/истории реестра должна работать только по явному allow-list и прекращаться, если не удалось создать `.reg`-бэкап.

О найденной уязвимости сообщайте владельцу проекта через https://tehadm.ru/ до публичного раскрытия.
