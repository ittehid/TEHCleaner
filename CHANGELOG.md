# Changelog


## 2.1.2 - 2026-10-07

- В основной таблице количество объектов и объём данных разнесены по отдельным столбцам.
- Результат очистки отдельно показывает число удалённых объектов и освобождённое место.
- Для записей реестра отображается количество записей, а размер остаётся пустым (`—`).

## 2.1.1 - 2026-10-07

- добавлена очистка кэша Delivery Optimization через штатный `Delete-DeliveryOptimizationCache -Force`;
- добавлена очистка старых журналов Windows Update / CBS / DISM / MoSetup / Windows Setup старше 30 дней;
- свежие журналы диагностики не удаляются;
- `Windows\Temp` уточнён как источник временных системных и установочных файлов;
- кэш `SoftwareDistribution\Download` переименован в «Старый кэш обновлений Windows»;
- существующие CrashDumps и Windows Error Reporting сохранены без изменения логики.

## 2.1.0 - 2026-10-07

- добавлена безопасная очистка пользовательской истории/MRU реестра Windows;
- очищаются только allow-list ветки `RunMRU`, `TypedPaths`, `WordWheelQuery`, `OpenSavePidlMRU`, `LastVisitedPidlMRU` и `RecentDocs`;
- перед изменением реестра автоматически создаются `.reg`-копии в `%LocalAppData%\TEHCleaner\RegistryBackups`;
- если резервное копирование не удалось, изменение реестра не выполняется;
- подробности очистки показывают конкретную ветку и количество удалённых записей;
- опасные эвристики для CLSID, ассоциаций файлов, автозагрузки, служб, SharedDLLs и Uninstall по-прежнему не используются;
- версия обновлена до 2.1.0.


## 2.0.2 - 2026-09-30

- Исправлено масштабирование интерфейса при 125–200% DPI.
- Колонки таблиц теперь подбирают ширину по содержимому и не обрезают категории, объёмы и статусы.
- Заголовки и строки DataGridView автоматически подстраиваются под DPI и шрифт.
- Главное окно уменьшено до более компактного размера.
- Исправлен блок «Что очищено»: заголовки больше не обрезаются, текстовые колонки делят доступную ширину, длинные пути доступны во всплывающих подсказках.
- Добавлены подсказки с полными значениями «Найдено», «Очищено» и количеством пропущенных объектов.

## 2.0.0 - 2026-09-30

- проект переименован из TEHADM в TEHCleaner;
- переход на .NET 10 и Windows x64;
- полностью переработано ядро очистки;
- добавлен двухэтапный режим «Анализ → Очистка»;
- интерфейс уплотнён до компактного рабочего окна;
- основная таблица теперь отдельно показывает «Найдено» и «Очищено»;
- добавлен блок «Что очищено» с детализацией по конкретным путям и кэшам;
- добавлен экспорт подробного TXT-отчёта;
- удалён небезопасный эвристический Registry Cleaner;
- удалено автоматическое удаление автозагрузки и ассоциаций файлов;
- добавлена безопасная файловая очистка с пропуском занятых/защищённых объектов;
- добавлены Chrome, Edge, Firefox, Opera/GX, Brave, Vivaldi, Яндекс Браузер;
- добавлена очистка DirectX shader cache, crash dumps, WER;
- добавлена расширенная очистка Windows Update;
- добавлены отмена операций и файловое логирование;
- добавлена опциональная точка восстановления;
- постоянные права администратора заменены на повышение только по необходимости;
- добавлен self-contained win-x64 publish profile;
- репозиторий очищен от `.vs`, `bin`, `obj` и пользовательских файлов Visual Studio.
