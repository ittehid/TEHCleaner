# TEHCleaner 2.1.2

TEHCleaner — безопасный очиститель Windows 10/11 x64 на C# / Windows Forms / .NET 10.

Главный принцип версии 2.1: **сначала анализ, затем удаление**. Программа показывает объём найденных данных и выполняет выбранные задачи последовательно. Занятые и защищённые файлы пропускаются, а не становятся причиной аварийного завершения.

## Возможности

- временные файлы текущего пользователя;
- `C:\Windows\Temp` (временные системные и установочные файлы) с повышением прав только при необходимости;
- кэш миниатюр Проводника;
- DirectX Shader Cache;
- корзина (не включена в рекомендуемый набор);
- недавние документы как отдельная расширенная privacy-задача;
- crash dumps и Windows Error Reporting как отдельные расширенные задачи;
- безопасная очистка кэшей Chrome, Edge, Firefox, Opera / Opera GX, Brave, Vivaldi и Яндекс Браузера;
- очистка старого кэша загрузок Windows Update с корректной остановкой/возвратом служб;
- очистка Delivery Optimization штатной командой Windows без удаления закреплённых файлов;
- очистка старых журналов CBS / DISM / MoSetup / Windows Setup возрастом более 30 дней;
- очистка DNS-кэша;
- анализ размера и количества объектов перед очисткой;
- отмена длительной операции;
- компактный главный экран без перегруженного журнала;
- подробный результат по каждой очищенной области: путь, удалённые объекты, освобождённый объём и пропуски;
- экспорт отчёта об очистке в TXT;
- постоянные лог-файлы в `%LocalAppData%\TEHCleaner\Logs`;
- опциональное создание точки восстановления системы;
- запуск без постоянного UAC и повышение прав только для выбранных административных действий;
- безопасная очистка пользовательской истории/MRU в реестре Windows с обязательным автоматическим `.reg`-бэкапом перед удалением.

## Очистка реестра

TEHCleaner 2.1 очищает только заранее разрешённые пользовательские ветки истории Windows: `RunMRU`, `TypedPaths`, `WordWheelQuery`, `OpenSavePidlMRU`, `LastVisitedPidlMRU` и `RecentDocs`. Перед изменением каждой существующей ветки программа делает экспорт `.reg` в `%LocalAppData%\TEHCleaner\RegistryBackups`. Если резервная копия не создана, очистка реестра отменяется.

## Что TEHCleaner намеренно НЕ делает

TEHCleaner не удаляет «подозрительные» CLSID/COM-записи, автозагрузку, ассоциации файлов, службы, `SharedDLLs`, Windows Installer и целые ветки `Uninstall` по эвристике отсутствующего файла. Такие записи могут быть корректными даже при необычной установке программы, поэтому автоматическое удаление исключено из публичного релиза.

Очистка браузеров не удаляет cookies, сохранённые пароли, закладки или пользовательские профили.

## Требования

- Windows 10/11 x64;
- Visual Studio с поддержкой .NET 10 для разработки;
- для обычной сборки требуется .NET 10 Desktop Runtime;
- self-contained publish включает runtime и не требует установки .NET у пользователя.

## Сборка

```powershell
dotnet restore .\src\TEHCleaner\TEHCleaner.csproj
dotnet build .\src\TEHCleaner\TEHCleaner.csproj -c Release
```

## Публичный self-contained EXE

```powershell
.\scripts\publish-win-x64.ps1
```

Результат будет создан в `artifacts\win-x64`.

## Работа с формами в Visual Studio

`MainForm` и `AboutForm` сделаны обычными WinForms Designer partial-классами. Все основные элементы интерфейса находятся в `MainForm.Designer.cs` / `AboutForm.Designer.cs` и доступны через визуальный дизайнер Visual Studio.

## Безопасность

Перед публикацией релиза рекомендуется подписывать EXE сертификатом Authenticode и прикладывать SHA-256 хэш. Никогда не распространяйте сборку из неизвестного источника под тем же именем.
