# Contributing to TEHCleaner

Спасибо за желание улучшить TEHCleaner.

## Основные правила cleaner-задач

1. Очистка должна иметь чётко ограниченный набор путей или системное API.
2. Нельзя удалять пользовательские документы, cookies, пароли, закладки, автозагрузку, ассоциации файлов, драйверы и службы как «мусор».
3. Файловый cleaner не должен переходить по reparse points / junctions.
4. Занятый или защищённый объект должен быть пропущен, а не приводить к аварийному завершению.
5. Для административных операций используйте `RequiresAdministrator`; приложение не должно постоянно требовать UAC без необходимости.
6. Перед добавлением системной операции предусмотрите способ сохранить исходное состояние. Например, Windows Update cleaner возвращает службы в состояние, которое было до запуска задачи.
7. Новая задача должна корректно работать в режиме Analysis без удаления данных.

## Проверка перед Pull Request

```powershell
dotnet restore .\src\TEHCleaner\TEHCleaner.csproj -r win-x64
dotnet build .\src\TEHCleaner\TEHCleaner.csproj -c Release
.\scripts\publish-win-x64.ps1
```

Проверьте приложение на актуальной Windows 10 x64 и Windows 11 x64 в обычном и административном режимах.
